#  MindMate – Backend

##  About the Project
MindMate AI is an advanced mental wellness platform that leverages agentic AI to provide intelligent, empathetic, and continuous emotional support. It integrates multiple AI agents to simulate real-world mental health assistance.

##  Problem Statement
Current mental health solutions lack:
- Instant and continuous support
- Context-aware conversations
- Early risk detection systems
- Safe and moderated environments

This leads to:
- Delayed help-seeking behavior
- Poor accessibility
- Lack of intervention at critical moments

---

## Backend Overview
The backend orchestrates multiple AI agents and system components:
- Handles API requests
- Manages AI interactions
- Maintains contextual memory (RAG)
- Performs emotional and behavioral analysis
- Detects risk and triggers escalation

---

## Tech Stack
- Spring Boot
- Spring AI
- OpenAI / Ollama
- MongoDB
- RAG (FAISS / Vector Database)

---

## System Architecture

### AI Agents
- **Conversation Agent** – Generates empathetic responses  
- **Emotion Detection Agent** – Analyzes user emotions  
- **Memory Agent (RAG-based)** – Maintains context  
- **Escalation Agent** – Detects risks & triggers actions  
- **Moderation Agent** – Ensures safe interactions  

---

## Features
-  Multi-agent AI system (not a single chatbot)
-  Context-aware memory using RAG
-  Emotion detection & behavioral analysis
-  Risk detection & escalation mechanism
-  AI-moderated safe community support
-  Continuous learning from user interactions
